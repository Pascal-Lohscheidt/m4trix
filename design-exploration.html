Design critique — current site

What works
  • IDE status-bar footer is brilliant — totally on-brand and unexpected
  • Terminal install block looks authentic; not a styled fake
  • CLI-style $ read docs nav button is a sharp detail
  • Animated headline cycling arguments communicates the differentiators fast
  • Bento grid is modern and keeps the feature scan short
What to reconsider
  • Matrix rain + scanlines reads as "hacker aesthetic" cliché, not serious infra
  • All-green monochrome palette collapses visual hierarchy — CTAs, badges, and tags look identical
  • Bento cards have no visual weight differentiation; all six look the same importance
  • Hero has no diagram or visual — zero spatial intuition for how agents connect
  • "…no more graphs!" breaks the linguistic pattern of the headline cycle

01 — Why amber

Genuinely distinct

Every other AI/developer tool uses green or blue. Amber phosphor is immediately recognisable and signals "real terminal heritage" not "hacker movie."

02 — Tradeoff

Bolder commitment

This is a harder sell to conservative orgs. It leans into personality over polish — great for indie/OSS traction, trickier for enterprise deals.

03 — Nice detail

Blinking cursor in h1

The CSS-animated cursor in the headline is a one-liner but makes the page feel alive without a heavy JS animation library.
