<Update label="October 14, 2026" description="Unreleased · latest core v0.17.0" tags={["Features"]} rss={{ title: "October 14, 2026 — @m4trix/core updates", description: "production-ready runtime for agent networks, with context folds" }}>

### Breaking changes

- production-ready runtime for agent networks, with context folds (`core`) **BREAKING** ([00b1845](https://github.com/Pascal-Lohscheidt/m4trix/commit/00b184513053bf9c14bd1c62c3043d0719e6e458))

  Runs now have a lifecycle, limits, validation, tenant-scoped history and resumable streams, and
  agents can build their model context incrementally with context folds. Migration notes for every
  breaking change are in packages/core/CHANGELOG.md.
  
  - Run lifecycle: `endsOn(event, when?)`, `ctx.complete()` / `ctx.fail()`, `idleTimeout` and
    `maxDuration`, `onAgentError: 'fail' | 'continue'`, and `m4trix:run.completed|failed|cancelled`
    after which the stream closes. Agents, tools and skills get an AbortSignal.
  - Concurrency: per-run mailboxes, so a run's events are handled in order while runs proceed in
    parallel; `.concurrency(n)` per agent; transient events slide instead of blocking.
  - Limits and usage: `maxDepth` (25) and `maxEvents` (1000) by default, `ctx.reportUsage()` with
    optional `maxTokens` / `maxCostUsd`; events carry `eventId`, `ts`, `depth` and `causationId`.
  - Stores and tenancy: async pluggable `AgentNetworkStore`, `ctx.history`, an in-memory default
    with TTL and LRU, history namespaced by the principal `auth` returns, `EventTransport`, and
    `runStoreContract` / `runTransportContract` in `@m4trix/core/testing`.
  - Validation: 400 on invalid requests, strict emits against `.emits([...])`, enforced
    `channel.events([...])`, a wiring check at setup (`network.validate()`), validated params.
  - SSE: `id:` lines with Last-Event-ID resume from the store, a 30 s reconnect window,
    heartbeats, Express back-pressure, GET `?payload=`.
  - Tools: JSON Schema, `toOpenAI()` / `toAnthropic()` / `toAiSdk()`, typed errors,
    `executeForModel()`, `.timeout()` / `.retry()`, a trace span per call; skills stream.
  - Context folds: `ContextFold`, `SegmentedFold`, budgeted views with `ContextStrategy`,
    `.folds([...])` and `ctx.folds.<name>()`, cached on the event plane, compaction via
    checkpoint events; `history.context({ names, after })` and `history.latest()`.
  - Observability: `logger` and `onMetric` options, a tracer `onUsage` hook, cancelled status.
  - Public API: explicit exports with an API report, no Node built-ins (Edge runtimes),
    `effect` as a peer dependency, Node 20+.
  
  BREAKING CHANGE: streams close when their run ends and runs need `endsOn` or `complete()`;
  `ctx.history` replaces `runEvents` / `contextEvents`; `AgentNetworkStore` is async with a new
  interface; `auth` returns a principal; undeclared or invalid emits fail the run; runs default to
  25 hops and 1000 events; tools reject with typed errors; `NetworkTracer` end hooks take a status;
  `DepedencyLayer*` is renamed `DependencyLayer*`; the spawner, `Proxy.kafka` / `Proxy.socketIo`
  and the legacy LLM and socket.io helpers are removed; `effect` must be installed alongside.

</Update>

- replace channel sinks with proxy consumers (`matrix`) **BREAKING** ([90871b6](https://github.com/Pascal-Lohscheidt/m4trix/commit/90871b64d9dbe07a87e3f1c5de8c2c529bdd92d9))
